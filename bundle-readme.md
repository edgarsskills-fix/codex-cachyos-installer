# ChatGPT / Codex для CachyOS

1. Распакуйте весь ZIP в обычную папку на компьютере.
2. Откройте файл **Установить** двойным щелчком.
3. Нажмите **Установить** в окне и введите пароль администратора.
4. После установки нажмите **Открыть ChatGPT**. Приложение также появится в меню GNOME.

Требуется CachyOS / Arch Linux **x86_64** с GNOME, GTK4, libadwaita и polkit.
Само приложение уже находится в архиве. Интернет нужен, если pacman должен
загрузить недостающие системные зависимости, а затем для входа и работы ChatGPT.
Переустанавливать ОС или включать AUR не требуется.

Установщик зарегистрирует приложение как пакет `chatgpt`. Существующая более
старая версия обновляется; более новая не понижается. Если ChatGPT уже открыт,
после обновления закройте и снова откройте его.

В архиве находятся только приложение из исходного DEB и установщик. Вход в аккаунт
выполняется отдельно на другом компьютере. Профили, переписка и ключи с исходного
ноутбука сюда не включены.

Если файловая система запрещает запуск (например, флешка с `noexec`), скопируйте
распакованную папку в домашнюю папку. Если не сохранилось право на выполнение,
откройте свойства файла «Установить» и разрешите выполнение как программы.

При ошибке откройте «Подробности» в установщике. Лог сохраняется в
`~/.cache/codex-cachyos-installer/install.log`. Если менеджер пакетов занят,
дождитесь завершения другой установки. Если зеркала устарели, обновите систему
штатным инструментом CachyOS и повторите установку.

Для проверки архива без установки: `./Установить --check`.
Для удаления приложения: `sudo pacman -R chatgpt`.

Это сторонняя упаковка для CachyOS, не официальный установщик OpenAI.
Содержимое приложения и его лицензии принадлежат соответствующим правообладателям.
