# ChatGPT / Codex — установщик для CachyOS

Архив для переноса приложения на другой компьютер с CachyOS GNOME
x86_64. Из локального DEB создаётся обычный пакет pacman, а небольшой установщик
на GTK4/libadwaita устанавливает его через системный запрос пароля polkit.

## Установка

Скачайте ZIP из **Releases**, распакуйте **всю папку**, откройте **Установить**,
нажмите кнопку установки и введите пароль администратора. После установки
приложение появляется в меню GNOME под именем **ChatGPT**; внутри доступен Codex.

Подробная инструкция находится в [bundle-readme.md](bundle-readme.md).

## Что включено

- ChatGPT `26.1111.21308` из предоставленного локального DEB.
- Исходный код и скрипт сборки графического установщика.
- Пакет `.pkg.tar.zst`, метаданные и контрольные суммы внутри ZIP.

Двоичные файлы приложения не изменяются. Debian-скрипты, добавляющие APT-репозиторий,
не выполняются. AppArmor-профиль сохраняется и загружается только при активной
службе AppArmor. Интеграцию меню обновляют стандартные хуки pacman.

Установщик проверяет SHA-256 пакета, архитектуру, семейство ОС, свободное место и
версию установленного приложения. Он не понижает более новую версию, не закрывает
работающий ChatGPT и не изменяет его пользовательский профиль.

Приложение включено в ZIP, а недостающие зависимости pacman получает из настроенных
репозиториев. Установщик не выполняет полное обновление ОС и не добавляет репозиторий
обновлений приложения. Новую версию ChatGPT нужно упаковать и установить отдельно.

## Воспроизводимая процедура сборки

Нужны `base-devel`, `binutils`, `libarchive`, `zstd`, `python`, `gtk4`, `libadwaita`.

```sh
python3 build.py --deb /путь/к/chatgpt_amd64.deb
```

Версия и SHA-256 исходного DEB закреплены в [source.json](source.json).
Сборка отвергает другой файл. Двоичные файлы приложения упаковываются без strip.
Итог находится в `dist/`. Сборка не копирует файлы из установленных профилей.

Для новой версии сначала осознанно обновите `source.json`, проверьте зависимости
нового DEB и соберите новый выпуск. SHA-256 пакета вшивается в бинарный установщик.

## Проверки

```sh
python3 tests/check_bundle.py dist/ChatGPT-Codex-CachyOS-*-x86_64
python3 tests/check_install.py build/packages/chatgpt-26.1111.21308-1-x86_64.pkg.tar.zst /путь/к/chatgpt_amd64.deb
```

Вторая проверка устанавливает пакет в одноразовый корень pacman под fakeroot,
не выполняет системные хуки и сверяет все файлы приложения с исходным DEB.
Она не заменяет приложение в работающей системе.

`Установить --check` проверяет пакет без запроса прав и установки.
`Установить --screenshot /абсолютный/путь.png` показывает окно, сохраняет его снимок
и выходит без установки; удобно для проверки под Xvfb.

## Происхождение

Это сторонняя упаковка исходного приложения, а не официальный релиз OpenAI для Arch.
Внутри остаются оригинальные лицензии и уведомления. Этот репозиторий не предоставляет
прав на код приложения. Исходный DEB и артефакты не хранятся в Git: готовый ZIP
публикуется отдельным файлом GitHub Release.

Собственный код установщика распространяется по MIT. Лицензия установщика не
распространяется на приложение OpenAI и поставляемые с ним компоненты.
